# Third-party CC0 kits (raw source)

Nothing here is loaded by the game; `.gdignore` keeps Godot from importing it.
To use a piece, copy it into `assets/art/` (or run it through
`tools/asset-pipeline/hd2d/` first). See the `hd2d-assets` skill.

| Folder | Source | License | Fetched |
|--------|--------|---------|---------|
| `kenney_nature_kit/` | https://kenney.nl/assets/nature-kit (only glTF is tracked; other formats are gitignored) | CC0 (see `License.txt`) | 2026-10-15 |
| `polyhaven_ground/` | https://polyhaven.com/textures (1K diffuse JPGs) | CC0 | 2026-10-15 |

Poly Haven maps are photoreal. For the HD-2D look use them as palette and
detail reference, or downscale and palette-reduce them; don't use them raw.
Kenney's Tower Defense Kit already lives in `assets/Tower Defense Models/`.
