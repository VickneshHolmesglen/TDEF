# 3D Towers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Placed towers render as live 3D models in the Hd2dScenery world, aim at targets, sweep like sentries when idle, grow more intricate with tier and veterancy rank, and appear as rotating 3D models in the Inventory.

**Architecture:** `TowerInstance` (Node2D) keeps its public API and stays the thing mission code talks to. When a scenery is set and every piece of the tower has a model, it spawns a `TowerModel3D` under `Hd2dScenery` at `to_world(position)`, hides its 2D layer sprites, and forwards effects to the model; otherwise it renders exactly as today. Aim/sweep maths lives in a pure `TowerAim` class; per-crown motion is data (`TowerCrownMotion`). Pieces are glb files from the Blender kit, stacked on `Seat` nodes, with `Tier2..4` detail groups.

**Tech Stack:** Godot 4.6.2, GDScript (typed), gdUnit4, Blender 5.1 via Blender MCP (`tools/asset-pipeline/blender/tower_kit.py`), Godot MCP for live checks.

**Spec:** `docs/superpowers/specs/2026-11-07-3d-towers-design.md`

## Global Constraints

- Every `VisualInstance3D` a tower creates must use `layers = Hd2dScenery.RENDER_LAYER` (1 << 11), or the scenery camera won't draw it.
- Aiming is visual only: no change to targeting, fire timing, range or any combat number.
- No SubViewport per placed tower. The Inventory preview may use exactly one.
- Overlays stay 2D: rank chevrons, perk badge, HP bars, idle particles, damage numbers.
- 2D layered path stays as the fallback for any tower with an unmodelled piece. Painted art is not deleted in this plan.
- 2D hero/monsters draw over 3D towers (no depth sorting); accepted by the user until units go 3D.
- Never put `#` comments inside `.tscn`/`.tres` blocks.
- Engine-referenced assets in `assets/art/towers3d/`; raw renders in `assets/source/3d/tower_kit/`.
- After adding a `class_name` file, a glb, or a PNG: run `"C:/Users/Shaukan/Desktop/Godot_v4.6.2-stable_win64.exe" --headless --editor --path "G:/TDef" --quit` before any headless test or MCP run.
- Test command (one suite): `"C:/Users/Shaukan/Desktop/Godot_v4.6.2-stable_win64.exe" --headless --path "G:/TDef" --script tests/gdunit4_runner.gd -- -a <res:// path> --ignoreHeadlessMode`. Never run the full suite unless the user asks.
- Idle sweep default 60°/s, tracking cap 270°/s, per-tower ±20% idle speed variation and random start yaw (spec §5.3).
- Commit and push after each task (user standing preference). Commit messages reference the spec path.

## Review Focus

1. **Target freed mid-track** (monster dies between shots): crown returns to sweeping from its current yaw, no error, no jump. Test in Task 3.
2. **Tower removed or destroyed while its 3D model exists**: model is freed with the TowerInstance; nothing left floating in the scenery. Test in Task 6.
3. **Mission with no scenery profile** (`_scenery == null`): tower renders 2D exactly as today. Test in Task 6.
4. **Rank set before the model exists or rank lowered/reset (retry)**: flourishes match the final rank, no duplicates. Test in Task 8.
5. **Yaw wrap-around** (current 350°, target 10°): turns 20° the short way, not 340°. Test in Task 3.

**Files:**

**Interfaces:**
- Produces:

  - `var yaw: float` (radians; 0 = crown front faces the camera, +3D Z)
  - `var z_stretch: float = 1.0` (set by the owner from the scenery)

  - `static func yaw_for_direction(direction_2d: Vector2, z_stretch: float) -> float` — `atan2(d.x, d.y * z_stretch)`
  - `static func turn_toward(current: float, target: float, max_step: float) -> float` — shortest way, never overshoots

- [ ] **Step 1: Write the failing tests**

```gdscript
func test_yaw_for_direction_straight_down_screen_is_zero() -> void:
	assert_float(TowerAim.yaw_for_direction(Vector2(0, 1), 1.3)).is_equal_approx(0.0, 0.0001)

func test_yaw_for_direction_right_is_quarter_turn() -> void:
	assert_float(TowerAim.yaw_for_direction(Vector2(1, 0), 1.3)).is_equal_approx(PI / 2, 0.0001)

func test_turn_toward_wraps_the_short_way() -> void:
	var r: float = TowerAim.turn_toward(deg_to_rad(350), deg_to_rad(10), deg_to_rad(5))
	assert_float(wrapf(r, 0, TAU)).is_equal_approx(deg_to_rad(355), 0.0001)

func test_turn_toward_does_not_overshoot() -> void:
	assert_float(TowerAim.turn_toward(0.0, 0.1, 1.0)).is_equal_approx(0.1, 0.0001)

func test_idle_sweeps_at_idle_speed() -> void:
	var aim := TowerAim.new(0.0, 60.0, 270.0, true)
	assert_float(aim.step(1.0)).is_equal_approx(deg_to_rad(60), 0.0001)

func test_tracking_turn_rate_is_capped() -> void:
	var aim := TowerAim.new(0.0, 60.0, 270.0, true)
	aim.set_target(Vector2(0, -1), 2.0)  # straight up screen = PI away
	assert_float(absf(aim.step(0.1))).is_equal_approx(deg_to_rad(27), 0.0001)

func test_hold_expiry_returns_to_idle_from_current_yaw() -> void:
	var aim := TowerAim.new(0.0, 60.0, 270.0, true)
	aim.set_target(Vector2(1, 0), 0.5)
	aim.step(1.0)                       # reaches PI/2, hold expires at 0.5 s
	var before: float = aim.yaw
	assert_bool(aim.is_tracking()).is_false()
	assert_float(aim.step(0.1) - before).is_equal_approx(deg_to_rad(6), 0.0001)

func test_clear_target_resumes_idle_without_jump() -> void:
	var aim := TowerAim.new(1.0, 60.0, 270.0, true)
	aim.set_target(Vector2(1, 0), 5.0)
	aim.clear_target()
	assert_float(aim.step(0.0)).is_equal_approx(1.0, 0.0001)

func test_non_aiming_crown_ignores_targets() -> void:
	var aim := TowerAim.new(0.0, 60.0, 270.0, false)
	aim.set_target(Vector2(1, 0), 5.0)
	assert_bool(aim.is_tracking()).is_false()
```
